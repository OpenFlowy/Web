Keyboard
  • Enter: Create a new task directly below the current task.
  • Double Click: Focus the current task.
  • Tab: Makes an item a child relative to the previous sibling.
  • Shift+Tab: Makes an item a sibling of its parent.
  • Up, Down: Move across items.
  • Shift+Up, Shift+Down: Reorder.
  • Ctrl+Up, Ctrl+Down: Expansion.
  • Ctrl+Enter: Mark Checked.
  • Ctrl+Backspace: Delete.
About
Flowy is a web app similar to WorkFlowy, but better.
  • Offline: You can use it even in absence of an internet connection. After initially loading the website over an internet connection, you can use Flowy even if you get disconnected from the internet.
  • No Account Needed: Just open the web app and start using it; no need to create an account. You can export and import your data without fear of being locked-in. Later, if you feel like it, you can create an account and save your data online, thus enabling you to access your data from multiple devices.
  • End-to-end Encryption: (work-in-progress) You can choose to save your data in a way that no one can read it.
